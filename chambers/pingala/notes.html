01 · छन्दः · meters as a hypercube

Pingala, Chandaḥśāstra (c. 3rd–2nd c. BCE) → Halāyudha's commentary (10th c.)

The idea

Pingala lists every meter of n syllables as a string of laghu (light, ।) and guru (heavy, ऽ). If I read laghu = 0 and guru = 1, a meter is just an n-bit binary string, and there are 2ⁿ of them. Those are exactly the corners of an n-dimensional cube with coordinates ±1.

Two corners share an edge when the meters differ in one syllable. In code that's one line: the XOR of the two indices has a single 1-bit.

// vertex i is meter i; an edge flips exactly one syllable
for (let i = 0; i < 1 << n; i++)
  for (let b = 0; b < n; b++) {
    const j = i ^ (1 << b);
    if (j > i) edges.push([i, j, n - 1 - b]);   // b = which syllable changed
  }

Counting faces with the Meru Prastara

A k-dimensional face frees k coordinates and pins the other n − k at ±1:

$$f_k(n) = \binom{n}{k}\,2^{\,n-k}$$

The binomial is row n of the meru-prastāra, the stepped "mountain" Halāyudha reads out of Pingala's sutras 8.34–8.35. Same triangle Europe later credits to Pascal. For the tesseract: 16 corners, 32 edges, 24 squares, 8 cubes, 1 tesseract. Sanity check I run in the tests: $$\sum_k (-1)^k f_k(n) = 1.$$

Turning in a plane

In n dimensions you don't rotate "around an axis", you rotate in a plane: pick two axes, apply a 2D rotation to them, leave the rest alone (a Givens rotation). There are C(n, 2) planes. The scene only turns planes that touch a hidden axis (index ≥ 3), because the other three are ordinary 3D rotations you can already do by dragging. A quarter turn maps the cube onto itself, so I snap the matrix back to integers at the end of each turn to kill float drift.

Projection is a pinhole camera applied once per extra dimension: drop the last coordinate w and divide the rest by (d − w). That's why the tesseract looks like a cube inside a cube.

The walk and the music

The gold spark visits every meter once, changing one syllable per step: a reflected Gray code, \(g(i) = i \oplus \lfloor i/2 \rfloor\). It's a Hamiltonian cycle on the hypercube. Each step plays a santoor note whose pitch rises with the number of gurus, in Raag Bhupali. The background kaleidoscope always has 2n mirrored wedges, so its symmetry tracks the dimension.
