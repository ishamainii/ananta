05 श्रीयन्त्र: an optimisation problem

The classical yantra, after Kulaichev (1984) and Tahta (1992)

Setting it up

Nine triangles, symmetric about a vertical axis, inside a unit circle: four point up (Śiva) and five point down (Śakti). Triangle i has a horizontal side at height bᵢ, half-width wᵢ and an apex on the axis at aᵢ. I read the structure off a published reference drawing and checked it numerically:

  • the two outer triangles have apexes and base corners on the circle (w = √(1 − b²));
  • each of the other seven apexes sits exactly on another triangle's base line;
  • eleven points (per half) are triple concurrencies, where three lines pass through one point.

That leaves 9 heights + 7 widths = 16 unknowns and 11 equations. The Jacobian has full rank 11, so the yantra is a 5-parameter family: fix five heights and the rest is determined. That is why drawing it by hand is so difficult, and why Kulaichev treats it as a system of conditions [kulaichev1984].

Concurrency as an equation

Write each line as normalised (A, B, C) with Ax + By + C = 0. Three lines meet in a point exactly when

$$\det\begin{pmatrix}A_1&B_1&C_1\\A_2&B_2&C_2\\A_3&B_3&C_3\end{pmatrix} = 0.$$

That's smooth in the unknowns, so it suits Newton's method.

Solving it

Hold the five free heights fixed, and take Newton steps on the other eleven unknowns with a finite-difference Jacobian. A backtracking line search halves the step if it would make the residual worse. Converging from a scrambled start takes a handful of iterations. Quadratic convergence shows up as the residual curve falling off a cliff, and each marked point turns green when its determinant drops below 10⁻⁹.

const J = jacobian(x)[:, free];           // 11 × 11
const dx = solve(J, -residuals(x));
let λ = 1; while (‖r(x + λ·dx)‖ ≥ ‖r(x)‖) λ /= 2;
x = x + λ·dx;

Tests (python + node): the reference yantra satisfies all eleven conditions to 3×10⁻¹⁶; Newton recovers it from a perturbed start; and moving a free height gives a different, still exact, yantra.

Honest caveats

Traditional yantras vary, and Tahta (1992) looks critically at some of the claims made about the yantra's geometry [tahta1992]. What's drawn here is one well-defined mathematical idealisation, not the only "correct" yantra.

Where it went next

The method used here, Newton's method with a line search on a set of geometric constraints, is the same kind of solver inside modern CAD software, where a designer fixes a few lengths and angles and the program places everything else. Like the yantra, those drawings usually have a few free choices and many conditions that must hold exactly.
