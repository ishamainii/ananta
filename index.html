Indian mathematics you can walk inside.

Ananta (अनन्त, "without end") is a set of seven interactive rooms. Each one takes a single result from Indian mathematics, checks it with tested code, and turns it into light and sound. Every claim links to its source.

    How to play

    every chamber works the same way

    1. One idea per room. Each chamber draws one piece of mathematics exactly. Only the coloured light behind it is decoration, and the glow slider turns it off.
    2. Walk around it. Drag to circle the maths. Scroll or pinch to move inside it. Double-click to return to the front.
    3. Follow the steps. A short guide opens the first time you enter and points at each part of the screen. Press ? to see it again.
    4. Read the key. The key on the left says what each colour and line means.
    5. Listen. A number in the scene chooses every note, and all notes come from Raag Bhupali. Press why this sound to see which number chose which note.
    6. Ask. Press ✦ ask or g and type or say what you want, for example "show 6 dimensions" or "what is a guru syllable".
    7. Check the sources. Press n for the history, the full mathematics and the papers behind every claim.

    About

    I'm Isha, a data science student at Emory. This project started with one question. What would Pingala's binary meters or Mādhava's infinite series look like if you could stand inside them?

    Code: github.com/ishamainii/ananta. Built with Python, NumPy, pytest, three.js, GLSL and the Web Audio API.
